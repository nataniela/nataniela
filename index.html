📚 Sistema Web de Gestão para Trabalho de conclusão de curso(escolar)

O Sistema Web de Gestão Escolar é uma aplicação desenvolvida como projeto de TCC, com o objetivo de facilitar a administração de informações escolares de forma digital, organizada e eficiente. O sistema permite a gestão de alunos, professores, turmas e notas, substituindo processos manuais e reduzindo o uso de ferramentas informais como papel ou mensagens dispersas. Este projeto foi desenvolvido com foco em melhorar a comunicação e organização dentro do ambiente escolar, garantindo maior rapidez no acesso às informações e melhor controlo dos dados académicos. Objetivo do sistema Criar uma plataforma centralizada e automatizar o processo de gestão escolar, permitindo acompanhamento contínuo, submissão de trabalhos e avaliação organizada entre estudantes,orientadores e coordenadores. Funcionalidades principais - Submissão de TCC pelos estudantes - Acompanhamento do progresso do projeto - Avaliação e feedback dos orientadores - Organização de fases do TCC - Gestão de utilizadores (estudantes,orientadores e coordenadores) Benefícios - Centralização das informações do TCC - Melhor comunicação entre estudante e orientador - Redução de processos manuais - Maior organização e transparência - Facilidade no acompanhamento do progresso Tecnologias utilizadas - HTML - CSS - PHP - MySQL - JavaScript Estado do projeto Em desenvolvimento contínuo como parte do trabalho de conclusão de curso (TCC).
